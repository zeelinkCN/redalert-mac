# 本机验证记录

验证平台：Apple M4、macOS 27.2，客户端使用稳定的 macOS 26.5 SDK 编译。

已完成：

- 原生客户端 Release 构建和 ad-hoc 签名验证。
- 11 项核心检查：版本识别、文件校验、独立副本、持久化、配置备份与恢复、中文路径、参数传递和全屏配置。
- 固定版本 Wine 11.21 安装包的 SHA-256 校验与自动安装。
- 自动安装 Rosetta；真实 Wine WoW64 32 位 cmd.exe 自检通过。
- 下载并部署红警 2、尤里、共和国之辉三个独立的简体中文档案，包含中文字库与音乐。
- 为三个游戏建立独立 Wine prefix，并成功注册原版 Blowfish 组件。
- 在客户端界面确认三个档案均显示已导入，版本切换正常；已实际发起原版游戏启动。
- 安装到 `/Applications/红警作战中心.app`；生成并校验 DMG。

尚未完成的全面验收：不同显示器与缩放设置、全部 MOD 单位和地图、长时间遭遇战、存档反复读写、完整战役及互联网联机。Wine 游戏窗口未向当前的 macOS UI 自动化工具提供可访问的应用标识，因此本次没有把进程启动或窗口绘制当作完整对局验证。

默认预置资源以遭遇战为主，不含完整战役和过场动画。客户端按当前显示器设置无边框全屏；鼠标释放和窗口切换由 cnc-ddraw 提供。
