红警作战中心首个公开预览版：用原生 macOS 客户端管理并启动原版 Windows 红警，无需手动准备 Wine 或开发环境。

### 下载与安装

- **Apple Silicon Mac（M1 及更新芯片），macOS 13+**：下载 `RedAlertMac-v0.1.0-macos-arm64.dmg`，打开后拖入 Applications，从启动台打开。
- 首次选择版本后点击「下载并部署」，自动下载、校验并配置运行环境、游戏资源、简体汉化和音乐。首次部署需要联网。
- 预览包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。macOS 如拦截，请按系统提示在「系统设置 → 隐私与安全」允许打开。

### 本版功能

- 红色警戒 2、尤里的复仇、共和国之辉默认部署配置，以及完整游戏目录导入。
- RA 风格中文启动台，独立游戏副本、存档与 Wine 环境。
- 默认无边框全屏并跟随显示器分辨率；支持窗口模式与手动分辨率。
- **Ctrl + Tab** 释放鼠标，**Option + Enter** 切换窗口 / 全屏，**Command + Tab** 切换应用。
- 自动安装 Wine / Rosetta，检测 32 位运行能力并注册原版组件。

### 验证与范围

已通过 11 项核心检查、Release 构建、应用签名和 DMG 校验；本机已部署三个中文版本并实际发起原版游戏启动。完整对局、跨显示器适配和互联网联机仍需更多实测，详见[验证记录](https://github.com/zeelinkCN/redalert-mac/blob/v0.1.0/docs/verification.md)。

默认游戏分发包以遭遇战为主，不含完整战役及过场动画；已有完整版可导入。DMG 不内置游戏本体，默认游戏部署面向已拥有对应游戏的用户。当前仅发布 arm64 安装包。
